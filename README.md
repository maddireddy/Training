# Java Full Stack Developer Training Course
## T-Shaped Developer Program - Industry Ready in 12 Weeks

### 🎯 Course Objective
Transform beginners into **Day-1 Ready Full Stack Java Developers** with hands-on experience in modern enterprise technologies.

### 👨‍🎓 Target Audience
- Fresh graduates / Career changers
- Developers with bare minimum experience
- Anyone aspiring to become a T-shaped Full Stack Java Developer

### 🛠️ Technology Stack Covered
- **Backend**: Java (JDK 8, 11, 17, 21), Spring Boot, Microservices
- **Frontend**: React.js, HTML5, CSS3, JavaScript ES6+
- **Database**: MySQL, PostgreSQL, MongoDB
- **Cloud**: AWS (EC2, S3, RDS, Lambda, ECS)
- **DevOps**: Docker, Kubernetes, Jenkins, Git, GitHub Actions
- **Tools**: IntelliJ IDEA, VS Code, Postman, Maven/Gradle

### 📚 Course Structure (12 Weeks / 60 Days)

#### **Phase 1: Java Fundamentals (Weeks 1-3)**
- Core Java & OOP Concepts
- Collections Framework & Generics
- Exception Handling & File I/O
- Multithreading & Concurrency
- Java 8+ Features (Streams, Lambda, Optional)

#### **Phase 2: Backend Development (Weeks 4-6)**
- Spring Framework & Spring Boot
- RESTful API Development
- Database Integration (JPA, Hibernate)
- Authentication & Authorization (JWT, OAuth2)
- Microservices Architecture

#### **Phase 3: Frontend Development (Weeks 7-8)**
- React.js Fundamentals
- State Management (Redux/Context API)
- Component Design & Best Practices
- Integration with Backend APIs

#### **Phase 4: Cloud & DevOps (Weeks 9-10)**
- AWS Services & Deployment
- Docker Containerization
- CI/CD Pipelines
- Kubernetes Basics

#### **Phase 5: Full Stack Project (Weeks 11-12)**
- End-to-End Project Development
- Deployment to AWS
- Best Practices & Code Review
