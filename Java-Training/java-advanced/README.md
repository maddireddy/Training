# Advanced Java Training Module

This module dives into advanced Java features and concepts, building upon the fundamentals covered in the Core Java module.

## Getting Started

### Prerequisites
- Completion of Core Java module or equivalent knowledge
- JDK 17 or later
- Maven 3.6.0 or later

### Building the Project
```bash
mvn clean install
```

### Running Examples
```bash
# Run specific examples using:
mvn exec:java -Dexec.mainClass="com.javatraining.advanced.ExampleClassName"
```

## Topics Covered

### 1. Concurrency
- Threads and Executors
- Synchronization and Locks
- Concurrent Collections
- CompletableFuture
- Fork/Join Framework

### 2. Java I/O and NIO
- File I/O Operations
- NIO.2 File System API
- Asynchronous I/O
- Memory-Mapped Files

### 3. Java 8+ Features
- Lambda Expressions
- Method References
- Streams API
- Optional Class
- New Date/Time API

### 4. Performance Tuning
- JVM Architecture
- Garbage Collection
- Memory Management
- Profiling Tools

### 5. Security
- Java Security Manager
- Cryptography
- Secure Coding Practices
- OWASP Top 10
