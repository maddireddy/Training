# Week 1: Java Fundamentals

## Learning Objectives
By the end of this week, you will:
- Set up Java development environment (JDK 8, 11, 17, 21)
- Understand basic Java syntax and data types
- Work with control flow statements and loops
- Master arrays and strings
- Create and use methods
- Understand basic Object-Oriented Programming concepts

## Prerequisites
- Computer with internet connection
- Curiosity to learn!

## Setup Instructions

### Option 1: GitHub Codespaces (Recommended - No Installation Needed!)
1. Fork this repository
2. Click "Code" → "Codespaces" → "Create codespace on main"
3. Wait for environment to load (JDK 17 pre-installed)
4. Start coding!

### Option 2: Local Setup
1. **Install JDK**:
   - Download from: https://adoptium.net/
   - Install JDK 17 (LTS)
   - Verify: `java -version`

2. **Install IntelliJ IDEA Community**:
   - Download from: https://jetbrains.com/idea/download
   - Install and launch

3. **Clone Repository**:
   ```bash
   git clone <your-fork-url>
   cd Training/Week-01-Java-Fundamentals
   ```

4. **Open in IntelliJ**:
   - File → Open → Select Week-01-Java-Fundamentals folder
   - IntelliJ will auto-detect Java project

## Common Errors & Solutions

### Error: "java: cannot find symbol"
**Solution**: Check variable/method spelling and declaration

### Error: "class X is public, should be declared in a file named X.java"
**Solution**: Filename must match public class name

### Error: "ArrayIndexOutOfBoundsException"
**Solution**: Check array bounds (index starts at 0)
